# Setup

Install `uv` if needed:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Sync the project environment:

```sh
uv sync
```

# Usage

```sh
uvx opendataloader-pdf -f markdown -o references/md references
```
